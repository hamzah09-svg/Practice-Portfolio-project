# hamza | Practice Portfolio Website

A simple, portfolio website built with HTML and CSS.

**Live site:** https://hamzah09-svg.github.io/portfolio/

## About This Project

I made this page to practise building a complete website from scratch. It shows who I am, what I know and the projects I have built.

## Sections

- **Menu:** stays at the top while scrolling
- **Hero:** welcome area with my name and buttons
- **About:** short intro and a few quick facts
- **Skills:** the tools and languages I use
- **Projects:** cards for my other web projects
- **Contact:** a button to send me an email

## Built With

- HTML
- CSS (Flexbox, gradients, hover effects, media queries for phones)

## Project Files

```
portfolio/
├── index.html    (the page structure and text)
├── style.css     (colours, layout and design)
└── README.md     
```

## to Run this site

1. Download or clone this repository.
2. Open the folder.
3. Double-click `index.html` to open it in your browser.

No installation needed.

## What I Learned

- Building a page layout with semantic tags (`header`, `main`, `section`, `footer`)
- Linking menu items to sections with `href` and `id`
- Using Flexbox to put items side by side
- Making a page work on small screens with `@media`
- Adding hover effects and smooth transitions
- Putting a project online with GitHub Pages
